# Goal

Create a personal website and deploy it publicly so anyone can access it.

## Current state
- No repo yet
- No environment/tooling set up yet
- Complete beginner to web deployment — wants the simplest possible approach

## Chosen approach (simplest path)
1. Write a plain static site (HTML/CSS, no framework, no build step).
2. Push it to a GitHub repository.
3. Enable GitHub Pages in the repo settings — GitHub hosts it for free at a public URL.

## Alternative (even less setup, no git)
Drag-and-drop the site folder into Netlify or Vercel's web UI for an instant public URL.
Less standard long-term, but zero git knowledge required.
